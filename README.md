
## Description
UniDone is a minimal task management web application built with Vite and Vanilla JavaScript.

## MVP Idea
The Minimum Viable Product (MVP) of web-app is a simple task manager that allows users to:

- Add new tasks
- Display tasks in a list
- Remove tasks

The goal of the MVP is to implement basic CRUD functionality for tasks while maintaining a clean project structure and Git workflow.

## Tech Stack
- Vite (build tool)
- Vanilla JavaScript
- HTML5
- CSS3
